## ✅ CORRECTION 2026-08-15: MiniCPM-V-4.6 IS allowed for submission

E-CUP 2026 rules state: "Разрешено использовать малые (до 4B) модели".

**MiniCPM-V-4.6 is ~1.2B params (NOT 4.6B)** — the "4.6" is the model version number,
not the parameter count. Architecture: Qwen3.5-0.8B (~0.8B) + SigLIP2-400M (~0.4B).
Confirmed by:
- Model README (mentions Qwen3.5-0.8B + SigLIP2-400M components)
- Official task docs `docs/tasks/task2_quality_data.md` which places it in
  the "Малые модели, до 3В" list
- ADR-002 (corrected 2026-08-15)

**Action**: MiniCPM-V-4.6 IS allowed for submission. Use for benchmarking
and as a lightweight alternative to Qwen3-VL-Embedding-2B (2B).

~2-3 GB on disk, 50% fewer FLOPs than Qwen3-VL-2B. Edge-deployment-friendly.
