## Context

Global RMSLE on 250k users hides per-segment problems: a model can excel at
"average" users but fail on "whales" (top 1% GMV) or "zero" users (45.9% have
predict=0). The AgentLTV paper (T3.6.3 research note, §4.1) recommends
bucket-level ranking + calibration diagnostics as a cheap visibility tool.

Idea accepted from docs/research/agent-ltv.md, implementation deferred until
now.

## GREEN

`src/ecup26_user_value/eval/bucket_diagnostics.py::bucket_diagnostics(y_true, y_pred, n_buckets=5) -> pd.DataFrame`:

Returns a DataFrame with one row per bucket:
| bucket | n_users | mean_true | mean_pred | rmsle_bucket | spearman_bucket |

Bucket assignment: rank-based quintiles on `y_true` (so buckets have ~equal size).
- bucket "zero": users with y_true == 0 (separate, always present)
- buckets "1-25%", "25-50%", "50-75%", "75-99%": quintiles of y_true > 0
- bucket "top 1%": top percentile of y_true

`spearman_bucket` is NaN for buckets with <2 unique predictions.

Optional integration with `ablation/runner.py::run_ablation`: add columns
`bucket, n_users, rmsle_bucket` per (model, features, fold). Output to a
separate `docs/results/ablation_v1_buckets.csv` (don't pollute ablation_v1.csv).
