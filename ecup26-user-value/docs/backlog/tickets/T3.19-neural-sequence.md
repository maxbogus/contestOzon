# T3.19 [P0] — Нейросеть на дневной последовательности (CSV-сабмит)
> **Статус: ✅ done** — итог зафиксирован, см. `docs/research/CATALOG.md` §4.

> **Приоритет: P0 (высокий).** Таблица плато на 1.6518; 14 гипотез wash/REJECT.
> Нейросеть — единственный класс сигнала, который таблица не видит (порядок,
> траектория, гэпы). **Сабмит — CSV** (`user_id, predict`), без Docker (R8 не
> применим к T3). Тренировка локально на RTX 5060 (8GB VRAM) / 24GB RAM.

## Hypothesis

Последовательная модель ловит траекторию (dormant->browse->cart->buy, разгон/затухание,
нерегулярные гэпы) — сигнал реактивации (T3.10.18: Dormant->Active 1.99x), который
агрегаты не видят -> fold-B <= 1.6800 (таблица: single 1.6821 / бленд 1.6813).

## Бюджет железа (жёсткое ограничение)

| Ресурс | Лимит | Расчёт |
|---|---|---|
| RAM | 24 GB | тензор 250k x L x 21: L=90->1.9GB, L=180->3.8GB, L=365->7.7GB (float32) |
| VRAM | 8 GB | на GPU только батч: 512x180x21 = 7.7MB + модель <1MB + градиенты -> <1GB |
| Время | ~2 ч на свип | ~30 конфигов x 2-5 мин на RTX 5060 |

**Правило**: весь тензор держим в RAM, в VRAM гоним только батчи (никогда не грузим
весь датасет на GPU). L=365 (7.7GB) — максимально допустимый; дальше не лезем.

## E0 — Sequence-датасет (инфраструктура)

- Токен = день: 17 raw-колонок + 4 структурных (day_of_week, days_to_ref,
  is_holiday_ru, days_to_next_holiday) -> D=21.
- Окно L (90/180/365). Спарсность честно нулями (гэпы = сигнал).
- Для каждого walk-forward origin T: тензор [L, 21] из строк <= T, лейбл
  log1p(GMV (T, T+30]).
- Тесты: (1) leak-check (дни > T не влияют); (2) размерность; (3) детерминизм при seed (R6).

## E1 — Санчек: flattened-MLP (низкий риск, быстрый ответ)

- Последние 90 дней -> флэттен в вектор [90x21=1890] -> MLP(256->128->1).
- Если даже это не бьёт таблицу -> направление мёртво, REJECT без свипа.

## E2 — Основной свип: GRU + attention (главное)

| Ось | Значения | Замечание |
|---|---|---|
| encoder | GRU / LSTM | causal, unidirectional |
| layers | 1 / 2 | |
| hidden | 32 / 64 / 128 | 128 на грани, но влезает |
| pooling | mean / attention (обучаемый query) | |
| loss | MSE(log1p) / Huber(log1p) | |
| batch | 128 / 256 / 512 | |
| lr | 1e-3 / 3e-3 | AdamW, cosine |

Фиксируем: L=180, 2 слоя, hidden 64, attention, MSE-log1p -> базовый GRU, потом
варьируем по одной оси. ~10-15 конфигов x 2-5 мин = <1 ч.

## E3 — Transformer (если GRU не дожал)

- 2 слоя x 4 головы, d_model 64, positional = days_to_ref + обучаемый позиционный эмбеддинг.

## E4 — Свип окна L и финальный гейт

- L in {90, 180, 365} на лучшем GRU (365 = 7.7GB RAM, последняя допустимая).
- Гейт: fold-B <= 1.6800 иначе REJECT. fold G — вторично.
- LB-слот только после прохождения гейта.

## Compliance / Forbidden

- R1: PyTorch (BSD). R4: без сети. R6: seed. CSV-сабмит (нет Docker для T3).
- НЕ тренироваться на днях 2026 (таргет). НЕ Ollama/vLLM/внешний API.
  НЕ random без seed. НЕ грузить весь тензор в VRAM (только батчи).
