## Вердикт

Гипотеза «серия неверных выводов + система ограничений → локальный минимум»
**ПОДТВЕРЖДЕНА** с уточнением механизма: консервативный фильтр (гейт + dead-end
лист) был наложен на валидацию, не совпадающую с таргетом, и математически обязан
отбрасывать сегментные/режимно-специфичные гипотезы, сохраняя глобальные
(локально-оптимальные).
