## Hypothesis

Для MSE в log-спейсе оптимальный предиктор нуля — hard 0 (T3.10.2), но свип дал
best t=0.05 (=нет порога). Причина-кандидат: P(y>0)-классификатор overconfident
(conformal q_hat=0.69 подразумевает 59.7% zero-membership при факте 45.9%) → порог
невозможно настроить. Решение — НЕ порог, а мягкое мультипликативное сжатие.

## Root cause link

P0-звенья 4 (только глобальные коррекции) + 5 (reject-by-default: hard-zero
REJECTED, а мягкий аналог не тестировали).
