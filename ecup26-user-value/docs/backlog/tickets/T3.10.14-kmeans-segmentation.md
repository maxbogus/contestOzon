# T3.10.14 — K-means segmentation / Mixture of Experts (вес 9 по ресёрчу)
> **Статус: ✅ done** — итог зафиксирован, см. `docs/research/CATALOG.md` §4.

## Hypothesis

Разные поведенческие группы (нули / средние / киты) заслуживают отдельных
«экспертов»: киты недопредсказаны (bias +0.84 на fold B, 4-5% юзеров), нули
перепредсказаны. Раздельная модель на кластер может закрыть хвост лучше, чем
один бленд.

## Expectations

- Кластеры должны быть интерпретируемы (нули/средние/киты по 143 фичам).
- Китовый эксперт должен улучшить bias на китах без потери на нулях.
- A/B sign-consistency: выигрыш на обоих фолдах без sign-flip.

## Series

- E1: K-means (k=3..6, на PCA-10 или на сырых фичах) + LGBM на каждом кластере;
  комбинирование взвешенным предсказанием (мягкая кластеризация).
- E2: отдельный «китовый» эксперт (top-5% по gmv) + общий для остальных.
- E3: комбо с shrink (T3.10.13): shrink на нулях + китовый эксперт на хвосте.

## Sweeps

k {3,4,5,6}; признаковое пространство для K-means (PCA-10 vs 143 фичи);
веса комбинирования.

## Compliance / Forbidden

R1/R6/R8. НЕ строить кластеры на тестовых юзерах (leak) - только на train.
НЕ повторять bucket-калибровку T3.9.12 (LB-degrade): эксперт - это МОДЕЛЬ
на сегменте, а не пост-хок коррекция.
