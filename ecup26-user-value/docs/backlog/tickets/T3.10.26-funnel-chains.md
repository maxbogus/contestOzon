### Цепочка 6 - Конверсия корзины по каналам
- `cart_conv_search = search_to_ord / search_to_cart`
- `cart_conv_cat = cat_to_ord / cat_to_cart`
- Смысл: выкупаемость товаров, добавленных через канал. В праздники: падение
  search-конверсии = сравнение цен; рост = «бери и заказывай».

### Цепочка 7 - Средний чек по источнику
- `avg_search_gmv` (есть) + `avg_cat_gmv = gmv_cat / cat_to_ord`
- Смысл: дороже целевые (поиск) или импульсивные (каталог) покупки. Праздники:
  чек из каталога растёт (подарочные наборы, сопутка).

### Цепочка 9 - Смешанный путь (миксер)
- `mixer_flag = (search=1 И cat=1 в один день)`
- `mixer_conversion = доля to_ord>0 среди миксеров`
- Смысл: «миксеры» имеют максимальную вероятность покупки, но если to_ord=0 -
  сложность выбора запутала.

### Цепочка 11 - GMV на поисковый запрос
- `gmv_per_search = gmv_search / searches`
- Смысл: монетизация усилий поиска. Праздники: должно расти (купонные запросы).
  Падение = выдача нерелевантна.

### Сегменты (бонус)
- «Охотники за скидками»: search=1, search_to_ord>0, gmv_search низкий.
- «Импульсивные дарители»: cat=1, cat_to_cart высокий, to_ord высокий, gmv_cat высокий.
- «Сомневающиеся»: to_cart>5, to_ord=0.
