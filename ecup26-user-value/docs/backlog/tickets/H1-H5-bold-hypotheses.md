## H1 — Сегментный hurdle (только на нулевом сегменте)

**Ledger:** H1.A1. REJECTED log-hurdle (sign-flip B/A) применялся ко ВСЕМ юзерам.
Hurdle-механизм (`pred_log = P(y>0)·E[log1p|y>0]`) — это RMSLE-оптимальная связка
для нулевого сегмента, где перепредсказание −1.42. Применить hurdle ТОЛЬКО там,
где P(y>0) < 0.5, остальным — baseline.
- Гейт: WIN P≤0.1 на B+A+P+G (M=500).

## H2 — Quantile-хвост (q=0.9 только для китов)

**Ledger:** H2.A1. REJECTED quantile-blend (2.16) смешивал квантиль со средним для
всех. Киты недопредсказаны (+1.74) — q=0.9 как предиктор ТОЛЬКО top-5% сегмента.
- Гейт: WIN P≤0.1 на B+A+P+G.

## H3 — Сезонная нормализация фич (zero_frac-тренд)

**Ledger:** H3.A1. REJECTED season-only (2.00) тренировался только на gift-данных
и терял историю. Нормализация фич на сезонный zero_frac-тренд (gift vs lull)
сохраняет всю историю, но убирает сезонный дрейф.
- Гейт: WIN P≤0.1 на B+A+P+G.

## H4 — Sequence-энкодер как источник фич для GBDT (не NN-предиктор)

**Ledger:** H4.A1. «Neural path exhausted» — для NN-ПРЕДИКТОРОВ (5 провалов).
Непроверено: GRU-энкодер → эмбеддинги 64/128 → фичи в LGBM (T3.10.9 TBD).
- Гейт: proxy < 1.70 на fold B + WIN P≤0.1 на B+A+P+G.
- EV низкий, делать после M1/G2.

## H5 — Эмпирический калибратор proxy→LB

**Ledger:** H5.A1. Константа «LB ≈ proxy − 0.035» дрейфует (P6). Эмпирический
калибратор по историческим парам (isotonic/linear, LOOCV) точнее константы.
- Гейт: MAE(калибратор) < MAE(константа).
