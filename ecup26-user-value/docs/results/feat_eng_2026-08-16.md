# Feature engineering experiment (T3.7.3 Cycle #1) — 2026-08-16

## Setup

Per meta-prompt T3.7.5 Cycle #1: 4 feature groups implemented in
`src/ecup26_user_value/features/build_features.py`:
- Calendar (day_of_week, month, quarter, is_weekend, is_holiday_ru)
- Rolling windows (gmv_avg_7d/14d/30d, orders_avg_*, gmv_max_30d, n_active_days_30d)
- Cross-features (recency_x_frequency, recency_x_avg_order_value, frequency_x_monetary)
- Customer tenure (days_since_first_purchase, is_new_customer)

Tested with LightGBM regressor on a **10k user subsample** of train.parquet
(full dataset: LightGBM fit timed out at 600s with default params).

Calendar features (day_of_week, month, etc.) have **zero** importance

## Caveats

- **Subsample (10k of 250k users)**. Full dataset LightGBM fit timed
  out at 600s; needs optimization (fewer estimators, smaller num_leaves,
  or early stopping) before T3.7.6 integration.
- **mae/rmse** are misleading — the subsample's GMV distribution differs
  from full population (small users dominate).
- **model_rmsle 2.3189** is on the **subsample only**. On full dataset,
  expected to be higher but still well below 5.5611 (BTYD).
- **Calendar features unused** — may be dropped or replaced with
  more granular seasonality (week-of-year, holiday distance).
