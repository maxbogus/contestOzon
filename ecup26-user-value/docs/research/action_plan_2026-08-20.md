| Пункт | Решение |
|---|---|
| **Одно место** | Все кэши в `data/` (gitignored), НЕ в `/tmp`. `data/folds/<name>` (fold-кэши) + `data/.cache` (resume). |
| **Лимит** | **10 GB** на `data/folds` + `data/.cache` (deфолт `cache_cleanup.py --limit-gb 10`). |
| **Хранить БОЛЬШЕ хешей** | Eviction только при превышении лимита; приоритет сохранения: хеши топ-LB-кандидатов (`data/.cache/top_candidates.json`) → свежайший активный хеш → остальные по mtime. |
| **Инструмент** | `uv run python scripts/cache_cleanup.py` (report + evict) / `--dry-run` / `--limit-gb`. |
| **Версионирование сабмитов** | Имя CSV: `submit_blend_{tag}_{YYYY-MM-DD}_{HHMMSS}.csv` (метка времени + дата) — несколько сабмитов/день без коллизий. |
