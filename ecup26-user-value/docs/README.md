# E-CUP 2026 — Исходная документация ODS

Извлечённая документация по 3 задачам E-CUP 2026. Контент очищен от JS/CSS/PNG-мусора.

## Структура

```
docs/
├── tasks/
│   ├── task1_matching.md         # Постановка задачи 1 (матчинг)
│   ├── task1_matching_data.md   # Описание данных задачи 1
│   ├── task2_quality.md          # Постановка задачи 2 (контроль качества)
│   ├── task2_quality_data.md    # Описание данных задачи 2 + глоссарий
│   ├── task3_user_value.md       # Постановка задачи 3 (предсказание GMV)
│   └── task3_user_value_data.md # Описание данных задачи 3
└── Правила E-CUP_23.07.26.pdf    # Регламент соревнования (исходный PDF)
```

## Источник

Все файлы извлечены из страниц https://ods.ai/competitions/e-cup-2026-{matching,quality,search}/
Дата извлечения: 2026-08-14.

## Использование

Эти файлы — **источник правды**. Кодогенерация и AI-агенты читают markdown напрямую
(`tasks/taskN_*.md`), люди — могут обращаться к исходным HTML на ODS.

Связь с основным бэклогом: `contest/tasks/TASK_N_*.md` содержат наш анализ и ссылки
на код, pipeline и данные — поверх этих файлов.
