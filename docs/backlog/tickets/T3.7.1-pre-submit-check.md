## GREEN

Runbook (no GPU):

```bash
# 1. Local dry-run on sample data
cd ecup26-user-value
python -u run.py --test_data_path data/sample_submit.csv --output_path /tmp/submit.csv
# expect: /tmp/submit.csv with columns user_id,predict, 250001 rows, unique IDs

# 2. R10 assertion (mandatory per ECUP_RULES.md)
python -c "import pandas as pd; df=pd.read_csv('/tmp/submit.csv'); \
    assert df.iloc[:,0].is_unique, 'duplicate IDs'; \
    print('OK: unique IDs')"

# 3. Docker build (CPU)
docker build -t ecup26-user-value:dev .
# expect: image <15 GB compressed, build time <5 min on a warm cache

# 4. Docker run with sample data
docker run --rm -v $(pwd)/data:/data ecup26-user-value:dev \
    --test_data_path /data/test.parquet \
    --output_path /data/submit.csv
# expect: container exits 0, submit.csv created

# 5. Schema sanity
head -1 /tmp/submit.csv  # "user_id,predict"
wc -l /tmp/submit.csv    # 250001
```
