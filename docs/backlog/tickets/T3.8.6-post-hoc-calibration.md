## Context

log1p-trained models are slightly biased in mean (pred mean ~44 vs truth ~84 on
the proxy). A post-hoc scale/shift calibration in log space could reduce RMSLE
without retraining.

## GREEN

1. On the walk-forward CV, fit a calibration: `pred_log_c = a * pred_log + b`
   (or multiplicative on GMV) using one fold; validate on the next.
2. Add `--calibrate` to benchmark_t3.py; pick the best calibration strategy
   (none / affine / per-quantile).
3. If it wins, bake the calibration constants into `predict_for_users`.

## RED

- `tests/test_30d_target.py::TestCalibration`: calibration improves proxy RMSLE
  on synthetic data or is a no-op (not worse).

## Verification

uv run python scripts/benchmark_t3.py --calibrate affine
uv run python scripts/validate_pipeline_30d.py
