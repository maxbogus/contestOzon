## Tier 2 (deferred, ~0.5h)

Deeper diagnostic metrics for ablation comparisons:

- **`spearman_global`** — Spearman correlation between predictions and
  ground truth on the entire test set. Already exists per-bucket
  (T3.6.17 bucket_diagnostics); add a global variant.
- **`rmse`** — Root Mean Squared Error. Useful for comparison with
  other submissions that publish RMSE.
- **`percentiles_alignment`** — Q10/Q50/Q90 of predictions vs ground
  truth, side-by-side. Captures calibration drift that RMSLE hides.
- **`stability_seed_variance`** — fit/predict N times with different
  seeds, report mean +/- std of RMSLE. Tests reproducibility.
- **`coverage_at_quantile`** — fraction of users where pred in
  [Q_lo, Q_hi] given true in same band. Tests calibration sharpness.

Use cases:
- Compare models in ablation table (T3.6.12/T3.6.18) more reliably
  than RMSLE alone.
- Detect when a model wins on RMSLE but loses on Spearman (a sign
  of overfitting to specific GMV ranges).

## Tier 3 (deferred, ~1h)

Visualization + statistical inference:

- **Calibration plot (PIT histogram)** — Probability Integral
  Transform: histogram of CDF(true | pred) should be uniform.
  Detects systematic miscalibration.
- **Adversarial slice evaluation** — break down RMSLE by:
  - cold-start users (< 7 days history)
  - churned users (no activity in last 30 days)
  - seasonal (December vs summer)
  - extreme values (top 1% whales, zero-bucket)
- **Bootstrap CI on RMSLE** — non-parametric 95% confidence interval
  for the RMSLE estimate. Tests whether model differences are
  statistically significant.

Use cases:
- Jury report visualization (E-CUP top-15 teams pitch to jury;
  calibration plot is a strong argument).
- Distinguishes "lucky fold" from "consistent improvement".
