## Context

After T3.8.1 provides the grid/random search core, extend the benchmarker with
model diversity and smarter search. Goal: find whether blending different
model families (XGBoost/CatBoost) beats single LightGBM, and let Optuna search
more efficiently than a hand-picked grid.

## GREEN

1. Add `xgboost` (and optionally `catboost`) to the benchmarker's train loop
   (both Apache-2.0; dev + runtime deps, image size check R8).
2. Blend in log space: average per-model raw log1p predictions; support
   weight search over the blend (grid over weights or simple mean first).
3. `--strategy optuna` (dev-only, MIT) for guided search on top of the grid.
4. Pairwise / coordinate refinement: vary 1–2 params around the best grid
   config while holding the rest fixed.
5. Report per-model AND blend RMSLE (walk-forward CV mean ± std).
