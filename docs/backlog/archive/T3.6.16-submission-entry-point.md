## GREEN

1. `run.py` with `python -u run.py --test_data_path <path> --output_path <path>`:
   - reads test parquet, fits BTYD (BTYDBaseline or SegmentedBTYD, choice deferred to ablation results)
   - predicts 250k user GMVs over 30-day horizon
   - clips at zero (RMSLE requires max(0, y))
   - writes `submit.csv` with columns `user_id,predict`
   - asserts `df.iloc[:, 0].is_unique` before writing (R10)
   - logs RMSLE on training data (sanity, not for leaderboard)

2. `Dockerfile` in repo root:
   - FROM python:3.11-slim
   - copies src/, run.py, pyproject.toml, uv.lock
   - RUN `uv sync --frozen --no-dev` (excludes lightgbm from image, R8)
   - ENTRYPOINT ["python", "-u", "run.py"]
   - image size <15 GB (R8)

3. `metadata.json`:
   ```json
   {"image": "<your_dockerhub_user>/ecup26-user-value:latest", "entry_point": "python -u run.py"}
   ```
