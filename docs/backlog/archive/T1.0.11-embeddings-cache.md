## Context

Encoding 500K items takes ~5 min. If we iterate on features (T1.2.x), we re-encode many times.
Cache prevents redundant computation but introduces invalidation complexity.

## Plan

1. **Cache key**: hash of (model_path, model_sha, item_text) → embedding vector
2. **Storage**:
   - Local: `data/embeddings/{model_name}/{item_hash}.npy`
   - Shared: `/shared_models/embeddings/` (if multi-user)
3. **Build cache once** for full items.parquet (~5 days CPU, 1.5 h H100)
4. **Incremental**: append new items, never invalidate
5. **Versioning**: store model SHA in cache filename
